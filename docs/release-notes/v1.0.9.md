> Quem já tem a **1.0.7 ou 1.0.8** atualiza por cima normalmente, sem perder dados.
> Quem ainda está na **1.0.6 ou anterior** precisa desinstalar e instalar de novo uma única vez (veja as notas da 1.0.7).

### Correções

- **Procurar atualizações sem o erro "GitHub API 403":** o app agora verifica as versões novas por um
  arquivo publicado junto com cada release, que não tem o limite de consultas por rede da API do GitHub.
  Isso vale a partir desta versão: na 1.0.8, a verificação ainda pode dar esse erro em algumas redes.
- Quando o GitHub recusar a consulta, o app explica o motivo e oferece o link da página de releases.
